# PROFITX Observatory visual identity

The canonical palette is defined in `PFX_BRAND_REFERENCE.md`, based on the image explicitly supplied by the user on 12 November 2026. Use deep black, metallic silver, vivid electric cyan/blue, saturated violet/magenta and neon PFX green. Do not replace these with a muted pastel or turquoise/lavender palette. Risk colors retain their semantic meaning.

The Analyzer opens with its search and a static composition around the existing official logo. The rings are brand decoration, not a score or live measurement. Repeated animated logo bubbles are removed. The project/token information remains available in a labeled disclosure below the real usage counters, rather than preceding the analysis task.

All eight tools retain their shared visible navigation. Existing APIs, scores, storage and live counters are unchanged. The global identity stylesheet follows the existing responsive stylesheet and preserves 44px mobile targets, 16px inputs, reduced-motion preferences, keyboard focus and the skip link.

Visual reference research included indexed GMGN documentation screenshots and Birdeye's X profile/terminal launch imagery. The aim is a research observatory identity rather than replicating another product's trading terminal. No third-party visual assets were copied into the product.

## Rendered checks

The production browser was checked at 1363 CSS px (1348 client/scroll width), and all eight tool routes at 340 CSS px (337 client/scroll width). Every route kept all eight navigation links with minimum height 44 px and no horizontal document overflow. The phone-width check uses native browser zoom, not physical iOS/Android hardware. The project disclosure opens to reveal the existing official mint and links. Desktop and narrow screenshots were inspected. A final refinement makes the narrow search action full width and carries violet through the tool-specific hero headings.

## Site-wide typefaces

At the user's request, every tool uses Sora for headings and Manrope for body copy, labels, navigation and controls. Large numbers retain tabular alignment. The old system-font-only stack is replaced by real variable fonts served by this application, with system fallbacks and `font-display: swap`. French accents are retained. Explicit monospace address blocks may remain for exact mint comparison; these are technical values rather than headings. The logo artwork itself is preserved.

Font sources: Google Fonts repository `ofl/sora/Sora[wght].ttf` and `ofl/manrope/Manrope[wght].ttf`, converted to WOFF without glyph subsetting. The corresponding SIL Open Font Licenses are retained alongside the files in `public/fonts/`. No runtime request to Google Fonts is needed.
